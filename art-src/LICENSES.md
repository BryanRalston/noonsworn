# Character licenses

Sela (`sela_rigged.glb`), the Dusk Mite (`mite.glb`), and the Shade Hound (`hound.glb`) are original procedural models built for Noonsworn. They are not from a CC0 pack. Geometry, the painted Sela atlas, and the baked vertex colours ship as meshopt-compressed glTF without a second quantization pass. The rigid `sela.glb` in the source folder is not used.
